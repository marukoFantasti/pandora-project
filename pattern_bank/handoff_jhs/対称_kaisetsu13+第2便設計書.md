# 対称 — kaisetsu本文（13パターン）+ 第2便設計書（shapes22・表型6・図なし3）

## A. kaisetsu本文（パターンid対応はCodeが symrows_* の単元×設問型で割付。逐語転写・{slot}は各パターンの既存名を使用）

### 線対称・対応する点
線対称な図形を対称の軸で折ると、ぴったり重なります。そのとき重なり合う点が「対応する点」です。点{p1}から対称の軸に向かってまっすぐ（垂直に）進み、軸をこえて同じ長さだけ進んだところにある点が、対応する点{ans}です。

### 線対称・対応する辺
折ったときに重なり合う辺が「対応する辺」です。辺の両はしの点それぞれについて対応する点を見つけ、その2つの点を結んだ辺が答えです。辺{e1}の対応する辺は辺{ans}で、長さは等しくなります。

### 線対称・対応する角
折ったときに重なり合う角が「対応する角」です。角{k1}の頂点に対応する点を見つけると、その点にできる角が対応する角{ans}です。対応する角の大きさは等しくなります。

### 線対称・性質（軸との関係）
線対称な図形では、対応する2つの点を結んだ直線は、対称の軸と垂直に交わります。また、その交わった点から対応する2つの点までの長さは等しくなります。つまり、対称の軸は対応する点どうしを結ぶ直線を垂直に2等分しています。

### 線対称・長さ
対応する点から対称の軸までの長さは、両側で等しくなります。方眼の目もりを数えて、軸からの目もりの数を左右で比べます。1目もりが{gcm}cmなので、目もりの数に{gcm}をかけて長さを求めます。

### 点対称・対応する点
点対称な図形は、対称の中心Oのまわりに180度回すと、もとの図形にぴったり重なります。点{p1}と中心Oを結んで、Oをこえて同じ長さだけまっすぐのばしたところにある点が、対応する点{ans}です。

### 点対称・対応する辺
180度回したときに重なり合う辺が「対応する辺」です。辺の両はしの点それぞれについて、中心Oをこえた反対側の点を見つけ、その2つを結んだ辺が答えです。辺{e1}に対応する辺は辺{ans}で、長さは等しくなります。

### 点対称・対応する角
180度回したときに重なり合う角が「対応する角」です。角{k1}の頂点から中心Oを通って反対側にある頂点にできる角が、対応する角{ans}です。大きさは等しくなります。

### 点対称・性質（中心との関係）
点対称な図形では、対応する2つの点を結んだ直線は、必ず対称の中心Oを通ります。また、中心Oから対応する2つの点までの長さは等しくなります。中心Oは、対応する点どうしを結ぶ直線のまん中にあります。

### 点対称・長さ
対応する点から中心Oまでの長さは等しいので、点{p1}から中心Oまでの目もりを数えれば、対応する点までの長さもわかります。1目もりが{gcm}cmなので、目もりの数に{gcm}をかけます。

### 多角形と対称・対応する点（正多角形）
正多角形は線対称な図形で、頂点の数だけ対称の軸があります。1つの頂点を通る軸で折ると、その軸の両側の頂点が順に対応します。点{p1}に対応する点は、軸をはさんで同じ位置にある点{ans}です。

### 多角形と対称・対応する辺（正多角形）
正多角形では、対称の軸をはさんで同じ位置にある辺どうしが対応します。辺{e1}の両はしの点それぞれについて対応する点を見つけ、結んだ辺{ans}が答えです。正多角形の辺はすべて同じ長さです。

### 多角形と対称・性質
正多角形のうち、頂点の数が偶数のもの（正方形・正六角形など）は線対称であり点対称でもあります。頂点の数が奇数のもの（正三角形・正五角形など）は線対称ですが点対称ではありません。対称の軸の本数は、頂点の数と同じです。

## B. 第2便設計書 — shape_set（判別・shapes型22行）+ 表型6行 + 図なし3行

- 要裁可(k)（まるこ・検収の一言で確定）:
  1. **記号保存・図形合成**: 選択肢の小図形（ア〜ク）は素材未転記のため、正答集合（線対称なもの＝ア、エ…）を保存するように**対称性カタログから割当てて合成**（line_set/sym_figureと同型の考え方）
  2. 円（u03_011/012）・円の交差/折り紙（028〜031）はcircle系またはテキスト形で第2便に含める。正五角形2個組合せ（013/014）は非格子図依存として**域外(d)候補**（まるこ判断）
  3. 表型6行=table kind・静的答／図なし3行=テキスト形

### B.1 kind: shape_set
```jsonc
{ "type":"shape_set", "labels":["ア","イ","ウ","エ","オ","カ"],
  "answer": { "line":["ア","エ"], "point":["イ","エ"] },   // 転記保存（設問が問う側のみ必須）
  "shapes":[ { "label":"ア", "kind":"iso_tri" }, … ],          // カタログから割当（合成）
  "seed": 7 }
```
- **対称性カタログ**（各形に線対称/点対称の真偽を固定）:
  - 両方: 正方形・長方形・ひし形・正六角形・十字・円
  - 線対称のみ: 正三角形・二等辺三角形・等脚台形・正五角形・矢印・T字・半円・ハート形
  - 点対称のみ: 平行四辺形・S字（Z字）・風車形（2枚羽）
  - どちらでもない: 一般の台形・L字・不等辺三角形・一般の四角形
- 割当規則: 設問が「線対称なもの」を問うなら、正答記号には線対称=真の形、非正答記号には線対称=偽の形を割当てる。「両方問う」行は2×2の真偽表で割当。同一行に同じ形を2回使わない
- 描画: 各小図形は共通の小キャンバス（等スケール・関門39包含）に描き、2〜4列のグリッド配置、記号ラベルは図の左上。対称軸・中心は描かない（判別が学習内容）
- 答え: 記号集合（順不同）→ **edge_setカタカナ集合採点をそのまま流用**（e-2で実装済）
- 関門（新設1本）: 割当の真偽表がカタログと一致（独立再計算）・同一行の形の重複なし・図形の対称性を座標から再計算してカタログと照合・ラベル帰属

### B.2 表型（6行）
- 行=図形名（正三角形〜正六角形／正方形・長方形・ひし形・平行四辺形・台形）、列=線対称／点対称／軸の本数。答えは静的（○×・本数）。既存table kindで受容（第3便流儀・空欄=□）
- kaisetsu（1本・共通）: 正多角形は頂点の数だけ対称の軸があり、頂点の数が偶数なら点対称でもあります。四角形では、正方形・長方形・ひし形は線対称と点対称の両方、平行四辺形は点対称だけ、台形は等脚台形のときだけ線対称です。

### B.3 図なし3行（u03_016/022/023）
- テキスト形・語答え（例:「無数にある」「円の中心」）。kaisetsu（共通）: 円はどの直径で折ってもぴったり重なるので、対称の軸は無数にあります。また円は、中心のまわりに180度回してももとの形に重なるので、点対称でもあり、対称の中心は円の中心です。
