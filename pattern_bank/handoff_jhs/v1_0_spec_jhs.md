# 生成器 v0.9 → v1.0 拡張仕様(jhs数学バンク対応)

作成: 2026-08-09 設計セッション / 実装: Claude Code / 承認: まるこ
方針: **全て加法設計**。無宣言・未使用時は従来挙動と完全一致 = g02〜g06ゴールデン差分ゼロが設計的に自明。

## 0. 関門(着手前後)

- 着手前: 現行mainでPythonゴールデン(g02〜g06)+JS verifyパリティを一度回し基準を固定
- 実装後: 同基準で**差分ゼロ**+等価性ベクター(新ヘルパ込み)全一致+JS verifyパリティ全学年
- いずれかで差分が出たら即停止・報告

## 1. answer_domain(パターン宣言・既定=従来)

パターン最上位キー `"answer_domain"`:
- 無宣言 or `"positive_int"`: 従来どおり ans > 0 を要求(既定)
- `"any_int"`: ans は任意整数(0・負を許容)
- `"nonzero_int"`: ans ≠ 0 を要求

verifyの返却キー名は `answer_positive` を維持し、意味を「宣言ドメイン内か」に拡張する(テストハーネス互換)。既存バンクは全て無宣言 → 挙動不変。

## 2. verify の負数対応(重要・バグ予防)

現行 `nums_from_slots` は本文から `\d+` を抽出し、許可集合(スロット値のint)と照合する。負スロット値 −6 が本文に「−6」と出ると、抽出は 6、許可集合は −6 で**必ず不一致になる**。

修正: 許可集合へスロット値 v を加える際、**v と abs(v) の両方**を加える(quantity・表示派生も同様)。既存バンクは全て正値 = abs(v)==v で挙動不変。

## 3. SAFEヘルパ追加(全て整数演算+文字列結合・反復のみ・JS同一手順)

| 関数 | 仕様 | 例 |
|---|---|---|
| `fmt_signed(n)` | n≥0→str(n)、n<0→"−"+str(-n)。マイナスは U+2212 | fmt_signed(-5)="−5" |
| `fmt_coef(n)` | 先頭項の係数: 1→""、−1→"−"、他→fmt_signed(n) | fmt_coef(-1)="−" |
| `fmt_coefj(n)` | 連結項の係数: 1→"＋"、−1→"−"、n>1→"＋"+n、n<−1→"−"+\|n\| | fmt_coefj(4)="＋4" |
| `fmt_termj(n)` | 連結定数項: 0→""、n>0→"＋"+n、n<0→"−"+\|n\| | fmt_termj(-49)="−49" |
| `sgn_str(n)` | n<0→"−"、それ以外→""(負分数の符号前置用) | sgn_str(-3)="−" |
| `sqrt_coef(n)` | n=k²·m(m平方因数なし)分解のk。d=2から d·d≦残り の反復で d² を割り尽くす | sqrt_coef(48)=4 |
| `sqrt_rad(n)` | 同分解のm | sqrt_rad(48)=3 |
| `fmt_sqrt(n)` | 符号込み√表示: 0→"0"、\|n\|=k²m で m==1→fmt_signed(±k)、k==1→[−]"√m"、他→[−]"k√m" | fmt_sqrt(-80)="−4√5" |

- 全て math ライブラリ不使用・Euclid反復文化と同一(Python/JS同一手順で言語間挙動差なし)
- FORMATTERS に `"signed": fmt_signed` を追加(answer_unit_system から利用可)
- 注意: fmt_coefj(0)は"＋0"を返さず**未定義扱い**とし、変数項が消えるケース(x²−49型)はバンク側で制約分割する設計規約(仕様書に明記のみ・実装はassert不要)

## 4. 負域スロット

`"range": [-9, -1]` / choices の負値を許容(Python randrangeは対応済)。JS側の乱数→値マッピングが負域で Python と一致することをシードベクターで確認し、`helpers_test_vectors.json` に負域サンプリングの照合ケースを追加。

## 5. 等価性ベクター追加

新ヘルパ8種 × 境界含む各5ケース以上(例: fmt_signed(0)、fmt_coef(±1)、fmt_termj(0)、sqrt_coef(1)、sqrt_rad(素数)、fmt_sqrt(平方数)、fmt_sqrt(負))。シード非依存でPython/JS照合。

## 6. 負分数の規約(バンク側規約・実装変更なし)

reduce_num/reduce_den・fraction系displayは**絶対値のみ**を受ける。符号は `sgn_str(...)` の計算スロットで別出しし、テンプレで前置(例: `{sg1}{f1}`)。生成器の分数機構は無変更。

## 7. display_canon 追記(jhsバンク側に記載・実装対象外の共有情報)

- 負数表記: U+2212(−)統一。ハイフン不使用
- 2次方程式の解2つの並び順・「x＝a，b」様式は実物精査後に正準確定(検収ポイント)
- 変域: 「a≦y≦b」形式、両端fmt_signed

## 8. 完了報告に含めるもの

version文字列(v1.0)、コミットID、着手前後ゴールデンmd5(全学年・不変確認)、等価性ベクター件数、JS verifyパリティ結果、負域サンプリング照合結果。

## 9. スコープ外(第1波でやらないこと)

多項式の汎用整形(係数配列→文字列)、√の分母有理化ヘルパ、π表示ヘルパ(整数係数×πはテンプレ文字列で閉じるため)、answer_domainの分数・実数拡張。必要が生じた時点で個別仕様化。
