# g03 テーマパックについて

g03専用のテーマパックはまだ作成していない(意図的)。g02の `themes/default_school_v1` を流用する設計だが、機械的に適用しないこと。

**注意**: g03の `div_object_pairs` は「わり算文脈で自然な物」(割り切れる・配れる・数えられる)に限定して選定している。テーマパックの語彙を無差別に流し込むと「63cmのリボンを7人で分けると1人分は9cm」のような文脈崩れは防げても、「あきかん」をわり算対象にするような語感の不自然さが混入しうる。テーマ語彙の適用は、パターン側が参照するレキシコンセット単位(div_object_pairs / ceil_contexts / floor_contexts / frac_unit_pairs)でホワイトリスト管理すること。

設計案を README_handoff.md タスク3の関門でまるこさんに提示してから実装に入ること。
