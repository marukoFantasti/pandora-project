# graph_choice便 受け皿設計書 — 変わり方のようすを表すグラフはどれ（g04 c02_u01 004/007）

- 要裁可(q)（まるこ・検収の一言で確定）:
  1. **記号保存・題材合成**: 正答記号（004=ア・ウ、007=ア・ウ・エ）は転記保存。4面の題材は2群のレコードから割当て（正答面=時間軸の題材、非正答面=種類別の題材）
  2. **面の描き方**: 時間軸の題材は折れ線（横軸=時刻/月/年）、種類別の題材は棒（横軸=種類）。生徒は「横軸が時間か種類か」で判別する＝教科書の学習内容そのもの
  3. 答えはedge_setカタカナ集合（順不同）で機械採点

## 1. 題材2群（行レコード・バンク由来の語彙で構成。新規固有名詞なし）
- 時間軸群（折れ線）: 1日の気温／1年の月ごとの気温／年ごとの身長／1週間の体温／時間ごとの水の温度／月ごとの売れた数
- 種類別群（棒）: すきなくだものの人数／クラスごとの人数／すきな動物／けがをした場所／持っている本の数（人別）
- 各面はタイトル（題材名）＋小型のグラフ（4〜6点／4〜6本）。縦軸・横軸のラベルは題材のレコードに持つ（度・人・cm・こ）

## 2. スキーマ
```jsonc
{ "type":"graph_choice",
  "panels":[ {"label":"ア","topic":"kion_1day","kind":"line"}, {"label":"イ","topic":"kudamono","kind":"bar"}, … ],
  "answer":["ア","ウ"],            // 転記保存
  "seed":5 }
```
- 割当: answerの記号に時間軸群から重複なしで割当、残りに種類別群から割当（決定的乱択）。同一図に同じ題材を2回使わない
- 描画: 2×2の小型パネル（等スケール・関門39包含）、各パネルにタイトルと記号、折れ線はxy_graph polylineの小型版、棒は同combo系の棒部品。数値ラベルは最小限（縦軸の端2つ）
- 系列データは題材ごとの妥当域から乱択（気温0〜30・人数0〜15等）。読み取りは問わないので値は答えに影響しない

## 3. 関門（新設1本）
- 割当検査（正答面=時間軸群・非正答面=種類別群・重複なし）・記号帰属・パネル等スケール・非重なり・決定性・答え集合の再導出=転記。悉皆=2行×seed100

## 4. kaisetsu（1本）
変わり方のようすを表すには、折れ線グラフが向いています。横の軸が時こく・月・年のように「時間」になっているグラフは、線のかたむきで変わり方が読めます。横の軸がくだものやクラスのような「種類」のグラフは、多い少ないをくらべる棒グラフで表します。時間の軸があるものを選ぶと、{ans}です。
