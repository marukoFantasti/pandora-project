# figure_builder 新kind設計書 — g05 C層(+B層 c04拡張)

対象: `pattern_bank/figure_builder.js`(rect_area / angle_sum 実装済み、v0.8 figure_params機構)への追加kind設計。
**本書は設計まで。量産(パターン化・スロットレンジ確定・実装)は次段。**

## 0. 全kind共通の設計原則(angle_sum で確立した原則の継承)

1. **ラベル束縛** — すべてのラベル(辺長・角度・頂点名・単位)は自分の幾何要素(辺・セクター・面)に束縛する。要素から独立した絶対座標配置を禁止。
2. **可動自由度の限定** — 衝突回避で動かせるのは *ラベル距離(半径相当)とフォントサイズのみ*。図形本体の寸法・角度・レイアウトは env の値から決定的に導出し、回避のために歪めない。
3. **全域機械スキャン** — 描画後に全テキストノード外接矩形を走査し、(a) テキスト間距離 ≥ 10px、(b) テキストと線分の重なりゼロ、(c) 意味判定(ラベルが束縛先要素の近傍にあり、他要素の方が近くならない)を検証。違反→ラベル距離調整→フォント縮小の順で再試行、収束しなければその env を棄却して再抽選。
4. **図と本文の同一env駆動** — figure_params はスロット参照のみ(`"{w1_disp}"` 等)。数値の直書き禁止(食い違いの構造排除)。
5. **fig_version** — 新kindはすべて `fig_version: 1` で開始。既存kindの描画は一切変更しない(後方互換)。
6. **表示スケール** — 辺長は実寸比を保った相対スケーリング(最長辺を基準ピクセルに正規化)。ただし比が極端(>4:1)になる env はパターン側制約で棄却し、図の視認性を生成条件に織り込む。

## 1. kind: `para_area` — 平行四辺形の面積(c10_u01)

**params**
```json
{"fig_version": 1, "kind": "para_area",
 "base": "{b_disp}", "height": "{h_disp}", "unit": "cm",
 "slant": "{s_deg}", "show_height": true}
```
- `slant`: 左辺の傾き(60〜75°をパターン側 choices で供給。描画側でのランダム化はしない=図もシード再現可能)。
- 高さは**内部の点線+直角記号**(1辺4px の正方形マーク)。高さラベルは点線に束縛。
- 底辺ラベルは底辺の下側中央に束縛。
- 頂点名は付けない(v1 は面積計算のみに使うため。求角と共用しない)。

**縮退・制約(パターン側に課す)**: base > height(横長に保ち高さ点線の視認性を確保)、比 ≤ 3:1。

**スキャン特記**: 高さラベルと左辺の距離判定(意味判定: 高さラベルの最近傍要素が高さ点線であること)。

## 2. kind: `tri_area` — 三角形の面積(c10_u02)

**params**
```json
{"fig_version": 1, "kind": "tri_area",
 "base": "{b_disp}", "height": "{h_disp}", "unit": "cm",
 "apex_ratio": "{ar}", "show_height": true}
```
- `apex_ratio`: 頂点の水平位置(底辺長に対する割合を千分率整数で。250〜750=鋭角三角形域)。
- **v1 は頂点の足が底辺内に落ちる鋭角・直角三角形に限定**(鈍角=高さの足が外に出る形は fig_version 2 で拡張。外部延長点線+直角記号の配置原則を別途設計してから)。
- 高さ点線は頂点から底辺への垂線。直角記号は足に配置。
- `apex_ratio = 0`(直角三角形・左直角)を許す場合、高さ点線は左辺と一致するため描かず、左辺自体に高さラベルを束縛する(分岐を kind 内で吸収)。

## 3. kind: `trap_area` — 台形の面積(c10_u03)

**params**
```json
{"fig_version": 1, "kind": "trap_area",
 "top": "{a_disp}", "bottom": "{b_disp}", "height": "{h_disp}",
 "unit": "cm", "offset_ratio": "{or}"}
```
- 制約(パターン側): top < bottom(上底<下底)、bottom ≤ 3×top(比の暴走防止)、height と bottom の比 ≤ 2:1。
- `offset_ratio`: 上底の左端オフセット(等脚〜片流れの範囲を千分率整数で)。
- 上底ラベルは上底の上側、下底ラベルは下底の下側、高さは内部点線+直角記号(para_area と同一部品を共有し二重実装しない)。

## 4. kind: `circle` — 円と円周(c12_u02)

**params**
```json
{"fig_version": 1, "kind": "circle",
 "given": "diameter",  // "diameter" | "radius"
 "value": "{d_disp}", "unit": "cm"}
```
- `given` により**直径線(中心を通る水平線)** または**半径線(中心→右端)** のどちらか一方だけを描く(両方描かない=問いと図の情報量を一致させる)。
- ラベルは線分中央上側に束縛。中心点は 2px ドット。
- 円周を問う問題では矢印等の装飾は付けない(v1)。円周率 3.14 は本文側の責務であり図には書かない。

## 5. kind: `cuboid` — 直方体・立方体の見取図(c02_u01/u02)

**params**
```json
{"fig_version": 1, "kind": "cuboid",
 "w": "{w_disp}", "d": "{d_disp}", "h": "{h_disp}", "unit": "cm",
 "cube": false}
```
- キャビネット投影(奥行 1/2・45°)で固定。投影方式を env に依存させない(図のブレ排除)。
- 隠れ線(奥の3辺)は点線。
- ラベル束縛: w→手前下辺の下、h→左辺の左、d→右下の斜辺の右下。単位はラベル文字列に含める。
- `cube: true` のとき `w` のみ表示し「1辺」ラベル形式(パターン側で分岐せず kind 側で吸収)。
- 制約(パターン側): 各辺比 ≤ 4:1。複合立体(L字等・c02_u02後半)は**対象外**(次々段。単純直方体2個の合成として別kindを設計する)。

## 6. kind: `tri_angle` / `poly_angle` — 三角形・四角形の角(c04_u02/u03、B/C境界)

angle_sum(実装済み)の直接拡張。確立済みの配置原則をそのまま使う:
**params**
```json
{"fig_version": 1, "kind": "tri_angle",
 "a1": "{a1}", "a2": "{a2}", "label": "あ"}
```
- 既知2角にセクター弧+角度ラベル(自分のセクターに束縛)、未知角に「あ」ラベル。
- 頂点座標は与角から決定的に構成(a1, a2 から第3角が決まるため、底辺固定+2角で一意)。
- `poly_angle` は四角形版(既知3角+未知1角)。パターン側制約: 各角 25°〜130°、和の整合は生成器の answer_formula(180−a1−a2 / 360−a1−a2−a3)と同一 env で構造保証。
- **これは angle_sum の params 拡張ではなく新kindとする**(angle_sum の描画コードに分岐を足さない=既存挙動の凍結を守る)。

## 7. kind: `table` — 対応表(B層・v0.9で実装対象)

仕様は `v09_js_port_draft.js` に記載(本セッションでバンク側5パターンが既に使用)。
配置原則の写像: ラベル→自セル束縛 / 可動→フォントサイズと列幅のみ / 全域スキャン→セルはみ出し0px+テキスト間10px+行列対応の意味判定。

---

## 8. 実装順序の推奨(次段)

1. `table`(バンク側パターン済み・検証コスト最小)→ 2. `tri_angle`/`poly_angle`(angle_sum 部品の再利用率最大)→ 3. `para_area`/`tri_area`/`trap_area`(高さ点線+直角記号の共通部品を先に作る)→ 4. `circle` → 5. `cuboid`。
各kindの受け入れ条件: (a) 全域機械スキャン合格率 100%(不合格は env 棄却で吸収)、(b) 同一シードで図が再現、(c) 図中数値が本文スロットと同一 env 由来であることの静的検査(figure_params 内の数値直書き検出 lint)。
