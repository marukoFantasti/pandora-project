## §1 構造(必須・機械検査済み)

- brief 6キー: semantic_territory / number_domain / answer_structure /
  figure / step_count / directives
- rationale 7キー: source_features / representation /
  constructive_guarantees / semantic_position / exclusions /
  figure_notes / pedagogy
- figure_notes: 全件文字列。図なしは「図なし(」始まりの理由文・
  図ありは設計記録(配置根拠・関門・値域決定)
- directives: by="marko"固定・date=YYYY-MM(月粒度)。
  2026-08-21に既存の YYYY-MM-DD 461件を月粒度へ統一済み(以後は月粒度で執筆)。
  裁可事項・確定値域・設計正準の変更履歴のみを載せる(感想は載せない)

## §2 各区画の必須要素

| 区画 | 書くこと | 書かないこと |
|---|---|---|
| source_features | 実物のどの構造の写しか・単元内の位置・実物の形式(問い方/答え形式) | 原文引用・素材名 |
| representation | 内部表現の選択とその理由(スロット設計・computed・機構の使い方)・機構の初出/流用の別 | 実装コードの詳細 |
| constructive_guarantees | 制約が何を保証するか(why単位)・値域の決定根拠(スキャン/実物レンジ)・転記排除の適用/構造的不能の別・受理組数 | 制約式の再掲だけ |
| semantic_position | 族・系列内の位置(始祖/対/掉尾)・学年間/章間の系譜・後続の受け口 | 単元名の再掲だけ |
| exclusions | 除外とその理由(退化/転記/域外)。除外理由は意味単位で個別に | 「特になし」(なしなら構造が内包する旨を書く) |
| figure_notes | 図あり: kind・配置根拠・関門・スキャン実証域/図なし: 図が不要な設計判断(図依存の分離先) | null・空文字 |
| pedagogy | 人間(まるこ/アイ)の教育所見の配列。**執筆時は空配列が既定**(g06の文字列形は歴史的許容) | AIの教育論 |

## §3 分量の健全域(①統計より・題材種別で層別)

- 区画合計の全体健全域: **114〜700字**(391件の実測全域=これを外れたら要審査)
- 題材種別の目安(平均): 図形設計型(角度・空間)350〜480 /
  文章題設計型(g02〜g05)330〜450 / 代数・手続き型(展開・因数分解・
  文字式・g01)180〜320
- **短さ≠薄さ**: 代数・手続き型の短さは題材の性質。図形級の厚みを
  水増ししない
- 参照圧縮(「同上」「同型」「符号のみ差」)は**族設計内で許可**——
  ペアの一方を厚く書き他方を差分参照で圧縮するのは正当な設計。
  ただし参照先が同族内に実在すること(§5)

## §4 語彙(ジャーゴン用語集——時代差の統一基準)

初期群(文章的)とネイティブ群(電文的)の両文体を**併存許容**とし、
評価は語彙の正確さで行う。正準ジャーゴン(意味を固定):

- **在庫**: 設計済み・未実装の候補(第N波在庫)/ **掉尾**: 系列の最終位置
- **統制設計**: 図・文面・値域を同型に揃え判定材料だけを変える設計
- **転記フリー構造**: 答が構造的に本文数値と衝突しない(証明を伴う)
- **幹参照**: _01接尾を省いたファミリ参照(g05_yakubun等)——実在必須
- **悉皆**: 全数機械検査 / **裁可**: まるこの承認(directives記録対象)
- **二段フロー**: 仮決め→機械確定(値域corr-0020・pos割当)
- **二層原則**: 格納=参照温存/訓練=実体解決(directives_ref・§5)

## §5 参照の規約

- corr-00XX参照: corrections_logに実在すること(①検査でリンク切れ0)
- パターンID参照: 完全形または幹参照。幹参照は実在ファミリに解決
  できること
- 散文参照(「同上」「同型」): 同族(同章の対・系列)内のみ許可。
  **訓練ペア生成時は実体解決または同族バンドル**(③で方式決定・
  二層原則の散文拡張)

## §6 モデル出力の検収基準(fine-tune後・⑤評価で使用)

未見briefに対する設計出力を以下で採点:

1. **構造合格**(機械): §1キー完全・figure_notes文字列・
   整合ハーネス通過相当
2. **保証の実在**(機械+目視): 書かれた制約・値域が実際に検証可能な
   形か(式として評価できるwhy・受理組数の妥当性)
3. **系譜の正確さ**(目視): semantic_positionの族・系譜が実在資産と
   整合するか(存在しない親を捏造しない)
4. **分量の題材適合**(機械): §3の層別域
5. **語彙の正確さ**(目視): §4ジャーゴンの誤用なし
6. 合格線: 1・2必須+3〜5で重大誤りなし。判定はまるこ/Fableの
   スポットチェック(⑤評価セットで運用)

## §7 運用

- 新規執筆(第3波以降)は本基準に準拠。参照圧縮・pedagogy空既定・
  YM date・幹参照実在をそのまま適用
- 補修は「基準違反」時のみ(①判定: 現391件は違反0・補修不要)
- 本基準の改訂はまるこ裁可+directives記録
