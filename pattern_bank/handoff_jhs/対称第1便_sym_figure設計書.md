## 1. kind仕様: sym_figure

### 1.1 スキーマ
```jsonc
{
  "type": "sym_figure",
  "sym": "line" | "point",
  "n": 10,                        // 頂点数 8〜14（転記ラベルの最大文字から下限を決める）
  "labels": ["A","B",…,"J"],      // 周回順（時計回り）・転記保存
  "map": { "A":"F", "B":"E", … },  // 転記の対応関係から導出した巡回写像（§1.2）
  "grid": true,                    // 方眼表示（素材に方眼語がある行=true・なければfalse）
  "show_axis": true,               // 線対称: 対称軸を破線表示／点対称: 中心Oを●表示
  "vertices": [[x,y],…],           // 整数格子座標・合成結果（anchor固定も可）
  "seed": 17
}
```

### 1.2 対応関係の逆算（配線時・Code）
- 周回順ラベルで、線対称の対応は i → (k−i) mod n、点対称は i → (i+n/2) mod n。転記の対応ペア（例: 点A↔点F、辺BC↔辺ED）から **k（またはn/2）と n の整合解**を求める。複数ペアが同じ写像を与えなければ**転記矛盾=skip+報告**
- 線対称でkが偶数なら軸は頂点を通る（固定点あり）、奇数なら辺の中点を通る。点対称はn偶数必須
- 転記に現れないラベルは写像から自動で決まる（設問に使わないだけ）

### 1.3 合成規則（形状生成）
- 方眼格子（12×12域）の整数座標に置く。**半分を作って写す**: 線対称=軸の片側に頂点列を乱択→鏡映で他半分／点対称=半周を乱択→180°回転で他半分
- 形状制約: 単純多角形（自己交差なし）・辺は格子に平行または45°（小6教科書の「読む型」=矢印・L字・十字・凸凹形）・最小辺長≥1格子・隣接辺の内角は90°/135°/270°のみ・頂点は全て相異なる
- ラベル: 各頂点の外側（多角形の内部と反対側）に配置・**line_setのラベル帰属/衝突回避資産を流用**・ラベル同士≥0.08
- 軸/中心: 線対称は軸を図形の外まで破線で延長・点対称は中心をOで表示（設問が中心を問う行はshow_axis=false）
- 日本語ハードコード禁止（記号・数値のみ）

### 1.4 設問型と答え（computed）
| 型 | 答えの導出 | 備考 |
|---|---|---|
| 対応する点/辺/角 | map適用（辺は両端点を写して正規化） | 静的文字列answer・edge_set採点（辺）/文字列一致（点・角） |
| 長さ・角度が等しい | map で写った辺/角 | 「辺ABと等しい辺」= 辺{map(A)}{map(B)} |
| 軸との関係 | 線対称: 対応点を結ぶ直線は軸に垂直・軸で二等分／点対称: 中心を通り中心で二等分 | 静的テキスト（転記保存） |
| 長さの数値（Ncm） | 格子1目盛=1cmとして辺長computed（軸/中心からの距離も） | 検算ゲート対象 |

### 1.5 関門（新設1本・corr-0030原則=描画と同じ幾何から独立再計算）
- 対称性検査: 鏡映/回転で頂点集合が自分自身に写ること（誤差0=整数格子）・mapの独立再計算一致
- 形状検査: 単純多角形・辺方向（0/45/90°）・内角集合・ラベル帰属・キャンバス内
- 等スケール（関門39が包含）・悉皆=51行の写像×seed100
- 数値答の検算: 辺長・距離を座標から再計算し answer と一致

### 1.6 転記矛盾・不適合の扱い
- 写像に整合解がない行／頂点数が14を超える行／対応が図形依存（非巡回）で表せない行 → skip+報告（行id・理由）
- 51行のうち skip 見込みは少数（対応ペアが1〜2組の行が多く整合解は広い）
