## 1. スキーマ
```jsonc
{ "type":"equal_parts",
  "shape":"circle"|"tape"|"rect",
  "den":4, "num":3,                 // 等分数・塗る個数（num=0で「等分だけ」の図）
  "den2":null, "num2":null,         // rectの2方向等分（g06面積図: 1m²を den×den2 に分け num×num2 を塗る）
  "unit_label":"1m",                // テープ/長方形の全体を表すラベル（バンク由来・省略可）
  "mode":"read"|"draw",             // read=塗り済みを見て分数を答える／draw=分数を与えて塗らせる（塗りなし・等分線のみ）
  "seed":3 }
```

## 2. 描画
- circle: 中心から等分線（半径）を den 本、扇形 num 個を塗り（12時から時計回り）。塗り=composite_circleのshade
- tape: 横長の帯（比率 6:1）を縦線で den 等分、左から num 個を塗り。上に「{unit_label}」（1m／1L）、両端に短い目盛
- rect: 長方形を縦に den 等分、den2があれば横にも等分（格子）。塗りは左下から行優先で num×num2（g06面積図は「1dLの列×3/4の行」など2方向の交差部を塗る＝num列×num2行の交差）
- draw型は塗りなし・等分線のみ（生徒が塗る）。問題文に分数を与える
- 日本語ハードコード禁止（ラベルはバンク由来）

## 3. 答え（computed）
- read: {num}/{den}（約分しない。2年は「1/2」「1/4」など単位分数中心）
- draw: 「{den}等分した{num}こ分に色をぬる」の列挙（小問ごと）
- g06面積図: 面積= num×num2 / (den×den2)（答えは既存パターンの{res1}と一致することを検算）

## 4. 可変化
- den∈行レコードの候補集合（g02: 2,3,4,8／g03: 2〜9／g06: 分母×分母）、num∈[1,den−1]。read型はnumを乱択・draw型は分数を乱択（答えは列挙をcomputed）

## 5. 関門（新設1本）
- 扇形角=360/den・テープ幅=W/den・格子=W/den×H/den2 の独立再計算（誤差0）・塗り個数=num（num×num2）・塗り面積比=num/den（誤差0）・塗りの連続性（左詰め/時計回り）・ラベル帰属・等スケール（関門39包含）・決定性。悉皆=行レコード全図×seed100

## 6. kaisetsu（図型共通・学年別に語り口を分ける）
- g02（read）: 同じ大きさに{den}つに分けた1つ分を、{den}分の1と書きます。色がついているのは{den}こに分けたうちの{num}こ分なので、{num}/{den}です。
- g03（draw）: {den}分の{num}は、全体を同じ大きさに{den}つに分けた{num}つ分です。まず全体を{den}等分して、そのうち{num}こに色をぬります。
- g06（面積図）: 1m²の正方形を、たてに{den}等分・横に{den2}等分すると、1つのますは1/({den}×{den2})m²です。色のついたますは{num}×{num2}こあるので、面積は{res1}m²になります。分数のかけ算で分母どうし・分子どうしをかける理由が、この図で分かります。
※ {den}{num}{den2}{num2}は行レコード表示派生・{res1}は既存
