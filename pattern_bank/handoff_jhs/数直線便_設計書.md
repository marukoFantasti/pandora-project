# 数直線便 受け皿設計書 — number_line（g04 9行＋g05 1行・学年横断部品）

- 前提: 概形第2便完了後・全48関門GREEN。対象=g04 c01（大きい数のしくみ4・小数の表し方3・小数のしくみ2）・g05（分数の性質1）
- 要裁可(n)（まるこ・検収の一言で確定）:
  1. **1kindで3系統を受ける**: 整数（万・億の大きい数）／小数（0.1・0.01刻み）／分数（0〜1をn等分）を同じnumber_lineで描く。目盛の刻みと表示形式だけを系統で切り替える
  2. **読み取り型のみ配線**（矢印↑の位置の数を答える／数の位置に対応する記号を選ぶ）。「数直線に↑をかき入れなさい」の作図型は、解答図機構が無い前提で**答え＝位置の数値列挙**（u01_002の打点列挙前例）とし、それも不可なら域外(d)
  3. 記号（ア・イ・ウ）と答えは転記保存、矢印の位置だけ合成（答えから位置が決まるため実質固定）

## 1. スキーマ
```jsonc
{ "type":"number_line",
  "system":"int"|"dec"|"frac",
  "min":0, "max":10000,                    // 表示範囲（intは万・億の単位を数値で。表示はlabel_fmt）
  "major":1000, "minor":100,               // 大目盛・小目盛の刻み（fracはden=等分数）
  "label_fmt":"man"|"oku"|"plain"|"dec1"|"dec2"|"frac",   // 大目盛のラベル形式（1万・2億・0.1・1/5…）
  "markers":[ {"label":"ア","value":3400}, {"label":"イ","value":7200} ],   // ↑と記号（転記保存）
  "show_values":"majors"                   // majors=大目盛のみ数値表示／ends=両端のみ／none
}
```

## 2. 描画
- 水平の直線、右端に矢じり。大目盛=長い縦線＋数値ラベル（下側）、小目盛=短い縦線。矢印↑は目盛の下から上向きに立て、その下に記号（ア・イ・ウ）
- 系統別:
  - int（大きい数）: label_fmt=man/okuで「1万・2万…」「1億・2億…」。0の位置に「0」。小目盛は1000（万系）/1000万（億系）等、転記の刻みに従う
  - dec: 0.1刻み（label_fmt=dec1）または0.01刻み（dec2）。「0.1を10こ集めると1」の読み取りは小目盛10本で1大目盛
  - frac: 0と1の間をden等分、大目盛は0と1のみ、小目盛にden等分（1/den刻み）。矢印の位置は分子/分母
- 矢印ラベルが隣接するときは、記号を上下交互（finishLabelsの帰属・衝突回避資産）。目盛数値と矢印記号は重ねない
- 日本語ハードコード禁止（万・億・記号はバンク由来）

## 3. 答え（computed）
- 「アの数は」= markers[].value をlabel_fmtで表示（3400→3400／0.7／3/5）
- 「◯◯の数を表す記号は」= value一致のmarker.label
- 「小目盛1つ分はいくつ」= minor（表示形式付き）
- 「イはアよりいくつ大きい」= 差（computed・系統の表示）

## 4. 可変化
- min/max/major/minorは行レコード固定（転記どおり）。markersのvalueは目盛上の点から乱択（ただし記号の並び順=左から転記の順を保存、隣接marker間≥2小目盛）。答えはcomputed

## 5. 関門（新設1本）
- 目盛の位置（座標）と値の対応を独立再計算（等間隔・大小目盛の整合）・矢印が目盛上に正確に乗る（誤差0）・記号帰属・矢印間隔≥2小目盛・数値ラベルの重なりなし・等スケール（関門39包含）・決定性。悉皆=10行×seed100

## 6. kaisetsu（系統別3本・共通の骨子）
- int: 数直線は、1目もりがいくつを表すかを先に読みます。大きい目もりが{major_disp}ずつ、小さい目もりが{minor_disp}ずつです。「{lb1}」の矢印は{n_from}から小さい目もり{k}こ分右にあるので、{ans}です。
- dec: 大きい目もりの間が10等分されているので、小さい目もり1つ分は{minor_disp}です。「{lb1}」は{n_from}から小さい目もり{k}こ分右にあるので、{ans}です。
- frac: 0と1の間が{den}等分されているので、小さい目もり1つ分は1/{den}です。「{lb1}」は0から{k}こ分右にあるので、{k}/{den}です。
※ {n_from}{k}{major_disp}{minor_disp}は表示派生の仮置き→Code申告

## 7. 実施順
1. 裁可(n)確定後、Codeが10行の全文引用付き棚卸し先出し（作図型の有無・刻み・記号数）
2. number_line受け皿→スモーク3枚（万系・0.01刻み・分数）→まるこ目視
3. 配線→kaisetsu転写→§3-3報告（g04は行レベル追補のためカバレッジ増なし・g05は+1）
