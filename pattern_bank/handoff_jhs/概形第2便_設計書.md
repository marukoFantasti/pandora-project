# 概形第2便 受け皿設計書 — approx_grid（方眼8行）+ approx_solid（立体6行）

- 前提: main（第1便配線済・全46関門GREEN）。対象=g06 c10_u01 方眼8（ます数え6+倍の2図2）・立体6。保留4（009/024/027・u01_029系）は据え置き
- 要裁可(m)（まるこ・検収の一言で確定）:
  1. **方眼型は「個数保存」**: 転記答に■/□の個数がある行は、格子上の分類結果がその個数と一致するseedを探索して固定（anchor）。個数が無く「約N」だけの行は ■+□÷2=N を満たす輪郭を探索
  2. **教科書手法の固定**: 一部かかるます（□）は0.5こ分として数える（■+□÷2）。これ以外の数え方（□を1こ／0こ）は採用しない
  3. **立体は「投影輪郭の合成」**: 直方体/円柱の見取図に、有機的な輪郭（第1便の星形曲線を投影多角形に適用）を重ねる。体積の式・答えは転記保存
  4. 倍の2図（u01_007/008）はapprox_gridの2図モード

## 1. approx_grid

### 1.1 スキーマ
```jsonc
{ "type":"approx_grid",
  "cols":10, "rows":8, "cell_cm":1,            // 1目盛の長さ（cm/m/km・行レコード）
  "outline":{ "seed":41, "amp":0.14 },          // 第1便の星形曲線（重心・基準半径は格子中央）
  "target":{ "full":18, "part":12 },           // 転記の■/□（無い行は null → ■+□÷2=area を目標）
  "target_area": 24,                            // 「約N」（■+□÷2）
  "pair": null,                                 // 倍の2図: {"a":{"shape":"circle",...},"b":{"shape":"square",...}}
  "show_marks": false }                          // 問題図では■/□を塗らない（数えるのが学習内容）
```

### 1.2 分類（ます目の判定＝描画と関門で同一導出）
- 各ますを5×5の格子点でサンプリングし、**25点すべて内側=■（完全）**、**1〜24点内側=□（一部）**、0点=外
- 輪郭は格子線と接しない位置に頂点を置く（接線判定の曖昧さを排除: 輪郭の各頂点座標を格子座標から±0.08以上離す）
- 答え: ■+□÷2（.5が出る行は転記答に合わせて表示、教科書は「約24.5cm²」も可）

### 1.3 合成（個数一致の探索）
- 基準形: 格子中央を重心とする星形曲線（第1便と同じ生成器）。基準半径Rと振幅ampを転記面積から初期化（πR²≈目標面積）
- seed 1..500 を決定的に走査し、分類結果が target（■・□）に一致した最初のseedをanchorとして行レコードに固定。target無しの行は ■+□÷2=target_area で判定
- 一致が見つからない行は R/amp を±10%で再走査（最大3段）→ それでも無ければ skip+報告（転記個数が幾何的に不自然な場合）
- 倍の2図: 図a・図bをそれぞれ上記で合成し、■+□÷2 の比が転記答の倍率（整数）と一致するよう探索

### 1.4 描画
- 方眼=sym_figureのgrid部品・輪郭=第1便の有機実線・■/□の塗りは show_marks=true のときのみ（解説用・本便では未使用）
- ラベル: 「1目もり{cell_cm}{unit}」を図の右下に1つ（バンク由来文字列）

### 1.5 関門（新設1本）
- 分類の独立再計算（■・□・面積）＝行レコードのanchor値と一致・格子線非接触・自己交差なし・キャンバス内・決定性
- 倍の2図は比の再計算
- 悉皆=8行×anchor（固定）+ 生成器経由の乱択100（show_marks=false の描画整合）

### 1.6 kaisetsu（共通1本・パターン分割はCode）
方眼を使っておよその面積を求めるときは、図形の中に全部入っているます（■）を1こ分、一部だけかかっているます（□）を半分（0.5こ分）として数えます。■が{n_full}こ、□が{n_part}こなら、{n_full}+{n_part}÷2＝約{ans}{unit}²です。1目もりが{cell_cm}{unit}のときは、ますの数に1ますの面積をかけます。
※ {n_full}{n_part}は行レコードのanchor値（表示派生）。倍の2図の行は「2つの図形の面積をそれぞれ求めて、大きいほうを小さいほうでわると約{ans}倍」の一文を末尾に追加

## 2. approx_solid

### 2.1 スキーマ
```jsonc
{ "type":"approx_solid",
  "base":"cuboid"|"cylinder",                    // みなし立体（既存cuboid/cylinderの寸法規約）
  "dims":{ "w":30,"d":20,"h":15 },               // cylinder: r,h
  "unit":"cm",
  "outline":{ "seed":9, "amp":0.10 } }            // 投影輪郭のゆらぎ
```

### 2.2 合成・描画
- みなし立体を既存の見取図（点線・寸法ラベル・隠れ線は描かない）で描き、その**投影シルエット多角形**（直方体は六角形、円柱は上下楕円+側面の輪郭）に対して第1便の星形曲線と同じゆらぎを適用した有機的な実線を重ねる
- 制約: シルエット面積比[0.92,1.08]・内外はみ出し・自己交差なし・寸法ラベルはみなし立体の辺に帰属（距離≦18px）
- 答え: 体積=既存式（w×d×h／r×r×3.14×h）。転記答保存（寸法は転記）

### 2.3 関門（新設1本）
- シルエット面積比・はみ出し両側・自己交差・ラベル帰属距離・体積=転記答・決定性。悉皆=6行×seed100

### 2.4 kaisetsu（共通1本）
形がでこぼこしていても、だいたい直方体や円柱とみれば、およその体積が求められます。{bn1}とみて、たて×横×高さ（円柱なら半径×半径×3.14×高さ）を計算すると、およそ{ans}{unit}³です。はみ出した分とへこんだ分がだいたい同じなら、この見積もりでよいことになります。
