# A. shape_set kaisetsu 6本（再送・逐語転写・{slot}は各パターンの既存名で）

### sen_hanbetsu
線対称な図形は、1本の直線で折ったときに両側がぴったり重なる図形です。まん中で折れる線が見つかるかどうかを、1つずつたしかめます。正方形や正三角形のように整った形だけでなく、矢印や十字のような形も、折って重なれば線対称です。

### tensym_hanbetsu
点対称な図形は、ある点を中心に180度回したときに、もとの図形にぴったり重なる図形です。正三角形は線対称ですが、180度回すと逆さになるので点対称ではありません。平行四辺形や風車の形は、折っても重なりませんが、180度回すと重なるので点対称です。

### tak_hanbetsu_ten
三角形や四角形の中で、180度回してもとの形に重なるものが点対称です。平行四辺形・長方形・正方形・ひし形は点対称ですが、台形や三角形は180度回すと形の向きが変わってしまうので点対称ではありません。

### tak_hanbetsu_ryo
線対称と点対称の両方にあてはまるのは、折っても重なり、180度回しても重なる図形です。長方形・正方形・ひし形がこれにあたります。平行四辺形は点対称だけ、等脚台形は線対称だけです。

### sen_jiku
対称の軸は、折ったときにぴったり重なる線のことで、図形によって本数がちがいます。正多角形は頂点の数と同じ本数の軸があり、円は無数にあります。それぞれの図形で軸を数えて、いちばん{ask1}ものを選びます。

### tak_sen_jiku
正多角形は必ず線対称で、対称の軸の本数は頂点の数と同じです。正三角形は3本、正方形は4本、正五角形は5本、正六角形は6本です。

# B. 概形第1便 受け皿設計書 — approx_shape（g06 c10_u01・みなし図形13行）

- 前提: 43efbd5・全45関門GREEN。対象=みなし四角形5・みなし三角形4・みなし円2・倍1（+図なし2はテキスト形/tableで同便に収容可）。方眼8・立体6は第2便
- 要裁可(l)（まるこ・検収の一言で確定）:
  1. **答え保存・輪郭合成**: みなし図形の寸法と答え（約N）は転記保存。不定形の輪郭は、みなし図形の周囲を決定性乱数でゆらがせて合成（line_set/sym_figure同型）
  2. **輪郭とみなし図形の関係を教科書どおりに**: 輪郭はみなし図形を「はみ出したりへこんだり」して、面積がおおよそ等しく見える形（輪郭面積＝みなし面積の±8%を関門で検算）
  3. 図なし2行はテキスト形/tableで同便収容

## B.1 スキーマ
```jsonc
{ "type":"approx_shape",
  "base":"rect"|"trap"|"para"|"tri"|"circle",   // みなし図形（既存面積kindの寸法規約を流用）
  "dims":{ "w":30, "h":20 },                     // rect: w,h／trap: a,b,h／para: b,h／tri: b,h／circle: r
  "unit":"m",
  "outline":{ "seed":17, "amp":0.12 },           // ゆらぎ: 振幅=みなし図形の代表長×amp、周期3〜5波
  "show_base":true,                              // みなし図形を点線で重ね描き＋寸法ラベル
  "pair": null }                                 // 倍を問う行のみ: 2図（base同型・寸法違い）
```

## B.2 合成規則（輪郭）
- みなし図形の各辺（円は円周）に沿って点を取り、法線方向に±amp×代表長の**決定性乱数**（lsRand）でずらし、なめらかな閉曲線（Catmull-Rom→折れ線近似）にする
- 制約: 自己交差なし・輪郭がみなし図形の**内外両方**にはみ出す（片側だけだと「大きめ/小さめ」に見えて概算の意味が崩れる）・輪郭面積÷みなし面積 ∈ [0.92,1.08]・輪郭がキャンバス内
- 描画: 輪郭=実線（地図・池・葉のような有機的な線）／みなし図形=点線／寸法ラベルはみなし図形の辺に帰属（composite_areaのラベル帰属資産・リーダーは不要の見込み）／直角マークはみなし図形側のみ
- 三角形の「地図・島・県形」行: 同じ規則で、base=tri・ampを大きめ（0.15）
- 円: base=circle・半径ラベル・輪郭は円周をゆらがせる

## B.3 答え（computed）
- 面積＝既存面積kindの式をそのまま（rect w×h／trap (a+b)×h÷2／para b×h／tri b×h÷2／circle r×r×3.14）。表示は「約{ans}{unit}²」（「約」は本文テンプレ側）
- まわり（円の行）＝直径×3.14
- 倍の行＝面積の比（整数倍になる寸法制約）
- 検算ゲート: 輪郭の多角形面積（座標から独立再計算）÷みなし面積が[0.92,1.08]・答え=みなし面積の式と一致

## B.4 関門（新設1本）
- 輪郭: 自己交差なし・内外はみ出し（法線方向の符号が両方出現）・面積比・キャンバス内・決定性（seed固定でバイト一致）
- みなし図形: 寸法ラベル帰属・直角マーク向き（composite_areaと同導出）・等スケール（関門39包含）
- 悉皆=13行×seed100

## B.5 kaisetsu（共通1本・パターン分割はCode）
およその面積を求めるときは、形をだいたい同じ大きさの長方形・三角形・円などとみて計算します。まわりの線は少しはみ出したり、へこんだりしていますが、はみ出した分とへこんだ分がだいたい同じなら、みなした図形の面積が、およその面積になります。{base_name}とみると、面積は約{ans}{unit}²です。
※ {base_name}（長方形／三角形／円…）は表示派生が無ければ仮置き→Code申告
