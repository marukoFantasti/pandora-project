# pandora_global 算数編 v1 — 運用ガイド（パートナー向け）

海外・継承語学習者に算数課題を配る際の設定ガイドです。数学ロジックは国内と同一で、
変わるのは日本語の**読み支援（ふりがな／ひらがな化）**だけです。ゼロAI・国内挙動は不変。

## 1. 海外モードの発火条件（自動）

生徒レコードが次のいずれかを満たすと自動で global モードになり、読み支援が入ります
（手動トグルはありません・モードバッジが常時表示されます）:

- `mode === 'overseas'`
- `globalSource === true`
- `vocabLevel` が存在する（値は問わない）

国内生徒（いずれも満たさない）は従来どおりで、読みエンジン・辞書は**ロードすらされません**。

## 2. readingSupport の設定（読みモード）

生徒レコード（または submission_data）の `readingSupport` フィールドで切り替えます。省略時は `'ruby'`。

| 値 | 表示 | 用途 |
|---|---|---|
| `'ruby'`（既定） | 漢字にふりがなルビ（`漢字《よみ》`） | 標準。漢字は残し読みだけ添える |
| `'kana'` | 本文を全ひらがな化 | 読字が特に弱い層。TTS音源にも使われる |
| `'off'` | 変換なし（漢字のまま） | 読み支援を切りたい場合 |

**付け方**: 生徒レコードに `readingSupport: 'ruby'`（等）を持たせるか、課題の submission_data に含めます。
無ければ ruby（既定）で動きます。

## 3. 推奨組み合わせ（v1 仮置き・運用で較正）

数学学年は**年齢相当**を基本にし、言語支援だけプロファイルで調整します。

| ① 会話流暢・読字弱（目安 JLPT N5） | 算数=年齢相当学年 / readingSupport=`'ruby'`（全付与） |
|---|---|
| ② 補習校経験あり | 算数=年齢相当学年 / readingSupport=`'ruby'`（レベル外のみは v1.1 で kanji_level 連動を検討） |

※ v1 は 2 行の仮置きです。トライアル生徒の実データで較正してください。
現状 ruby は「全漢字にふりがな」で、漢字レベル連動（レベル外のみルビ）は v1.1 候補です。

## 4. 既知の限界（v1）

- **図（SVG）内の漢字は未ルビ**（統計表のヘッダなどが中心・異なり48文字列）。v1.1 で対応予定。
- **UI ラベル（「正解：」等）は未ルビ**（仕様）。問題本文・答えのみ変換します。
- 英語ヒント（en_hint）・分かち書きは v1 スコープ外（v1.1 在庫）。

## 5. TTS（読み上げ）

海外レコードでのみ有効。読み上げテキストは `'kana'` 変換（全ひらがな）を音源にします。
文章題の読み上げは継承語児に特に有効です。
