# 解説backfill 棚卸し — g04（kaisetsu無し 53パターン）

- 用途: Fableが生徒向け解説（`kaisetsu`）を書き下ろすための棚卸し。1パターン=id・単元・本文テンプレ（{slot}名そのまま）・答え式・computed一覧・density/diff・図kind。
- 規則: `kaisetsu` は sentence_templates と同一リゾルバで `{slot}` を解決（computed名も参照可・`{ans}` 可・表示派生 `{X_disp}`/`{X_edges}` 可）。ひらがな1字ラベルは「」囲み（D10）。例示は静的数値でなく `{slot}` 参照で書く（可変生成と図のズレ防止）。pedagogy（設計ノート）は生徒に見せない。
- 注: バンクには `diff` 欄が無い（行の難度は原典側）。`density` は line_set のみ（例=low/確認・練習=normal）。図kindが「なし」のパターンは本文のみで解説する。
