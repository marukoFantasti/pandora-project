# C層kind 実装仕様書 — figure_builder.js 追加9kind(セッション2)

前セッションの設計書(figure_kinds_design_g05.md)を実装グレードに確定した版。
**幾何の「正」は fig_geometry_reference.py**。JS実装は同一の手順・定数で移植し、
geometry_test_vectors.json(8kind・40ケース)で各座標±0.5px一致を検収条件とする。

## 0. 全kind共通(確定事項)

- 配置原則は既存どおり: **ラベル自要素束縛 / 可動はラベル距離・フォントサイズのみ / 全域機械スキャン(テキスト間≥10px+テキスト-線分の重なりなし+意味判定)**。textBox/rectRect/boxSeg/distPtSeg 等の既存部品を再利用し二重実装しない。
- **描画可能性はパターン側制約が全域保証する**(悉皆検証済み: tri_angle 4,921組合せ・quad_angle 130,931組合せ・iso 46値 すべて成立)。スキャンは検収ネットであり、実行時の env 棄却・再抽選は行わない(env は生成器が確定済み)。スキャン不合格が受け入れテストで出た場合はバンク制約の強化で対処し、報告する。
- 座標系: リファレンスは **y上向きローカル座標**。SVG出力時の y反転・マージン付与は各kindの描画部の責務(プレビューHTML参照)。
- 未知kind・fig_version≠1 は既存どおり空文字返し(非破壊)。BUILDERS への登録のみで統合。
- 色・線種の既定: 図形本体 `#1a56c4` stroke-width 2 / 塗り `#eef4ff`、既知角ラベル `#1D9E75`、求める対象(あ・高さ点線・直角記号)`#C0392B`、点線 `stroke-dasharray 5,4`(既存angle_sum/rect_areaの配色慣行を踏襲)。
- **ラベル白フチ(halo)**: すべての寸法・角度ラベルは `paint-order="stroke" stroke="#fff" stroke-width="3"`（angle_sum と同一様式）を付与し、点線・実線との視覚分離を字形レベルで確保する（共有 `textEl` に実装）。
- **縦点線ラベルの強クリアランス不変条件(v1改訂)**: 高さ点線共通部品(para/tri/trap)の高さラベルと rhombus のたて対角線ラベルは、**その縦点線からテキストボックスの水平クリアランスを ≥12px** とする（先頭数字「1」の縦棒が点線と平行に紛れるのを字形の前段で防ぐ）。これは一般規則(テキスト-線分≥4px)より強い**部品固有の不変条件**として `_MinClearance` にアサート(`strongBad===0`)。この条件を課すラベルには「自要素が最近傍」の意味判定は課さない（ラベルは点線と側辺の間に置かれ、識別は位置＋赤色＋白フチで担保）。高さラベルのアンカーは足元からの上向きオフセット `clamp(0.15H, 16, 0.45H)`（背の高い図はくさびを広く、背の低い図は底辺から最低16px離す）。

## 1. tri_angle — params `{a1, a2, label}`

底辺 BC=260px 固定、B(左)に内角a1・C(右)に内角a2、頂点A=2射線の交点。
`h = L·tan(a1)·tan(a2)/(tan a1+tan a2)`、`ax = L·tan(a2)/(tan a1+tan a2)`。
h>260px なら全体を等比縮小(scale=260/h)。既知角: B・C に半径26pxの弧+ラベル(角の二等分方向・内側 r≈40px 起点、スキャンで距離のみ調整可)。未知角: A に大きめ弧(r=34px)+`label`(既定「あ」)を**既知角と同じく二等分方向・内側**に配置(初期半径=弧+14=48px、可動域 r∈[弧+10, 弧+34]=[44,68]、font 15→13→11。r≥44>弧34 で弧の外側=頂点から遠い側に置き弧と重ねない)。ラベル文字列は「{値}°」形式でkind側が°を付与。
> 注(v1改訂): 旧版は未知角ラベルを「二等分方向外側」としていたが、これは angle_sum(頂点1つ・辺2本の開き角)の慣行を三角形頂点に誤って持ち込んだもので、頂点から浮いて見えるため撤回。角系3kind共通で内側に統一(2r·sin(θ/2)≥ラベル幅15px を未知角の全値域=tri第3角30〜115°/iso底角30〜75°/quad第4角65〜100°で確認済み)。

## 2. tri_angle_iso — params `{apex, label}`

等辺長 190px 固定・頂点上。`base = 2·190·sin(t/2)`、`h = 190·cos(t/2)`。
頂角に弧+「{t}°」、左底角に未知弧+label。未知角ラベルは §1 と同じく**内側・二等分方向**(UN_IN: 初期r=48・可動域[44,68]・font 15→13→11)。**等辺2辺の中点に等長ティック(8px・辺に垂直)を必ず描く**(二等辺の根拠を図が示す)。底角は左右対称だが未知ラベルは左のみ(問いは1つ)。

## 3. quad_angle — params `{a1, a2, a3, label}`

**適応構成(固定手順・乱数なし)**: A原点、AB=180px(+x)、Dは∠A=a1 方向に AD 進んだ点。
AD は候補列 `[150,170,130,190,110,210,100,90]` を先頭から試し、**最初に最短辺≥42pxを満たすもの**を採用(なければ最良値)。C は「Bから 180°−a2 方向の射線」と「DからDA方向+反時計a3 方向の射線」の交点。凸性・内角検算・バウンディング(620×540)込みの成立判定はリファレンス実装 `_quad_try` と同一に。既知角 A/B/D に弧+ラベル、未知角 C に label。ラベル位置は既知・未知とも各頂点の内角二等分方向・内側(未知角は §1 の UN_IN: 初期r=48・可動域[44,68]・font 15→13→11)。

## 4. para_area — params `{base, height, unit, slant, show_height}`

スケール `min(260/b, 170/h, 24)`。頂点 A(0,0)-B-C-D、左辺傾き slant(60〜75°、バンクchoices供給)。
高さ点線: **D から真下** に垂線(foot=(off,0))、footに直角記号(8px)。ラベル: 底辺値+unit を底辺下中央、高さ値+unit を点線右側中央。点線・直角記号・高さラベルは `#C0392B`。

## 5. tri_area — params `{base, height, unit, apex_ratio, show_height}`

底辺スケール同上。頂点x = base_px × apex_ratio/1000(300〜700=鋭角域、バンク保証)。
高さ点線: 頂点から真下、foot に直角記号。ラベルは para_area と同配置規則(共通部品化すること: 「高さ点線+直角記号+高さラベル」は para/tri/trap で1実装を共有)。

## 6. trap_area — params `{top, bottom, height, unit, offset_ratio}`

スケール同上。上底左端x = (下底px−上底px)×offset_ratio/1000。
高さ点線: **上辺中点から真下**。ラベル: 上底値を上辺上、下底値を下辺下、高さを点線右。

## 7. rhombus_area — params `{diag_h, diag_v, unit}`

中心原点、`scale = min(240/max(d1,d2), 22)`。4頂点=対角線端点。**辺は実線・対角線2本は点線**。
ラベル: 横対角線値を中心の右下(横点線の下側)、たて対角線値を上半分の右側。ラベルは自対角線束縛(意味判定: 最近傍線分が自対角線)。

## 8. circle — params `{given: "diameter"|"radius", value, unit}`

半径90px固定・中心ドット2.4px。given=diameter→中心を通る水平弦(全幅)、given=radius→中心から右端の線分。**線は一方だけ描く**(問いと図の情報量一致)。ラベル「{value}{unit}」を線分中央の上側。円周を示す矢印等の装飾なし。

## 9. cuboid — params `{w, d, h, unit, cube}`

キャビネット投影: `scale = min(180/w, 150/h, 110/d, 20)`、奥行オフセット=(d·scale·0.5)·(cos45°, sin45°)。
前面 w×h 実線、上面・右面を薄塗り2階調(プレビュー参照)、**隠れ3辺(背面左縦・背面下2辺)は点線**。
ラベル: 横=前面下辺の下、高さ=前面左辺の左(text-anchor=end)、たて(奥行)=右下斜辺の右下。
`cube:true` のときは **wラベル1つのみ**表示(1辺)。ラベルは数値+単位のみ(たて/横/深さ等の名称は本文の責務)。

## 10. スキャン仕様(9kind共通・検収ネット)

対象=全テキストノード。合格条件: (a) テキスト間 rectRect≥10px、(b) テキストと非自要素線分 boxSeg≥4px、(c) 意味判定=各ラベルの最近傍要素が自分の束縛先(角ラベル→自弧/自頂点射線、寸法ラベル→自辺/自点線、セル→自セル)。調整自由度はラベル距離(角系: 二等分方向の r、寸法系: 辺からのオフセット)とフォントサイズ(15→13→11)のみ。`_<kind>MinClearance` 形式で機械検査関数をエクスポートし受け入れテストから呼ぶ(table と同形式)。
